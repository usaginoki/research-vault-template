# Backlog

Every candidate paper is a small note in `Backlog/` (properties only, from `Templates/Candidate.md`).
The tables below are live views of [[Backlog.base]]. Sort by clicking a column header, and edit
`status` / `priority` right in the table.

- **status:** `candidate` → `processing` → processed (the note moves to `Papers/`) · or `rejected` (+ `reason`)
- **priority:** 1 = process next · 2 = relevant · 3 = peripheral / background
- **found_by:** `search/<strand>` · **cited_by:** links to the processed papers whose references list it
- Workflow: `_tools/README.md` → *Backlog*
